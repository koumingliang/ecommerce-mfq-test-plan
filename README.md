# 电商系统 MFQ 测试计划（ecommerce-mfq-test-plan）

使用 MFQ（Models / Functional / Quality）框架为电商系统设计的体系化测试计划交付物。

## 业务范围

- 商品（SPU/SKU）、库存（可用/预占/已售）、购物车
- 订单生命周期（下单 → 支付 → 取消 → 发货 → 签收 → 退货）
- 外部系统同步（WMS / SC2P）

## MFQ 结构概要

- **M 模型层**：端到端业务流程模型、订单状态机、库存状态模型（守恒不变式）、外部交互模型、一致性边界（强一致 / 最终一致 / 对账节点）
- **F 功能层**：核心正向流程、库存同步一致性（预占/扣减/幂等/乱序）、边界场景（零库存/秒杀/拆单/退货）、关键 API 校验
- **Q 质量层**：性能指标、可靠性（重试/熔断/降级/补偿任务）、可观测性、安全性、可恢复性、版本发布准入/准出标准

## 优先级原则

- **P0** = 资金/库存安全 + 主链路（库存守恒、幂等、超卖禁止），每次发布 100% 回归
- **P1** = 高价值一致性场景与边界，纳入迭代
- **P2** = 低概率场景，自动化日常覆盖，不阻塞发布
